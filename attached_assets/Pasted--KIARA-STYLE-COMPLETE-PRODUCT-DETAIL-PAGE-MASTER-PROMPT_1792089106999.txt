**Right column: Product purchase panel**

### Section F — Size Selection

- Require a valid size selection before adding a size-dependent T-shirt to the cart.
- Show a helpful validation message if no size has been selected.
- Preserve the selected size when opening and closing the size chart.
- Do not mark every size unavailable unless the inventory data confirms that condition.

Include:
- Size labels.
- Chest measurement.
- Length.
- Shoulder measurement where applicable.
- Sleeve length where applicable.
- Units in centimetres or inches.
- Clear instructions for measuring a T-shirt.
- A size guide image or illustration if available.

All measurements must come from approved product data. If measurements have not been supplied, show a configurable placeholder or clearly indicate that the size chart needs to be completed. Do not invent exact garment measurements.

The modal must have a close button, keyboard accessibility and mobile-friendly scrolling.

### Section H — Add to Cart and Buy Now

The Add to Cart button must be functional.

- Validate current availability.
- Add the correct product, size, colour and quantity to the cart.
- Update the header cart count.
- Show a clear success message or cart drawer.
- Prevent accidental duplicate additions caused by repeated clicks.
- Preserve cart data according to the existing cart implementation.

The Buy Now button should take the user into the checkout flow with the selected variant if the website supports it.

Never show a successful addition if the operation failed.
